# Projeto de Infraestrutura Computacional — AD Corp

## Sobre o projeto
Projeto de infraestrutura computacional para a empresa fictícia AD Corp, do setor de Tecnologia, com uma matriz e duas filiais, totalizando aproximadamente 150 colaboradores.

A solução integra Arquitetura de Computadores, Sistemas Operacionais, Redes e IoT.

## Empresa

A AD Corp atua com desenvolvimento de sistemas, segurança cibernética e suporte técnico.

Matriz — São Paulo: 80 funcionários;<br>
Filial — Campinas: 35 funcionários;<br>
Filial — Santos: 35 funcionários.

Total aproximado: 150 colaboradores.
